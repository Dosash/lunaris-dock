# Работа с Lunaris Dock

Windows 11 x64, C# и WPF на .NET Framework 4.8. Запускайте команды PowerShell из корня. Точка входа — `src/Program.cs`. Скрипт `build.ps1` компилирует `src/**/*.cs` системным `csc.exe` и встраивает `Preferences.xaml` как ресурс.

Сначала проверьте `git status --short --branch` и выберите строку по задаче в [карте кода](docs/DEVELOPMENT.md#карта-кода). Для поиска по проекту используйте `git grep -n UpdateVisibility -- src tests`, подставив нужный символ. Такой поиск охватывает только отслеживаемые файлы.

- После изменения кода быстрая сборка — `.\build.ps1 -AppOnly`. Проверка именно этого EXE — `.\tests\Core.Tests.ps1 -ExePath .\build\LunarisDock.exe`.
- Проверяйте интерфейс в `--preview`. Для новых настроек сохраняйте совместимость с прежним `settings.json` и применяйте изменения в открытом окне. [Профили и настройки](docs/DEVELOPMENT.md#профили-и-настройки)
- Для изменений Пуска, настроек, упаковки и оболочки есть отдельные [проверки](docs/DEVELOPMENT.md#проверки). Установщик — основная загрузка, portable ZIP — альтернатива.
- Профили, журналы и снимки личного рабочего стола остаются локально. Перед отправкой проверьте состав коммита и данные его автора. [Публикация](docs/DEVELOPMENT.md#публикация)
