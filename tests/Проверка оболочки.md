# Приёмка Lunaris Dock в Windows 11

Используйте отдельную интерактивную учётную запись Windows 11 x64 или виртуальную машину с рабочим Проводником. Проверки перезапускают оболочку, блокируют экран и удаляют тестовую установку. На виртуальной машине сохраните снимок до установки программы.

В журнале прогона укажите выпуск Windows, номер сборки и обновления, разрешение, масштаб, исходную настройку автоскрытия и SHA-256 установщика. Отдельно отмечайте результат каждого действия и прикладывайте снимок или видеозапись при расхождении.

## Подготовка и повторяемые проверки

Откройте PowerShell в корне проекта. Первая полная сборка загружает закреплённую версию Inno Setup и сверяет хэш. Для сборки без сети передайте `-Iscc` с путём к ранее установленному компилятору.

~~~powershell
.\build.ps1
.\tests\Core.Tests.ps1
.\tests\Preview.Tests.ps1 -LaunchName 'Таблица символов'
~~~

В англоязычной Windows передайте `-LaunchName 'Character Map'`. Этот сценарий использует отдельный временный профиль и закрывает окно запущенной им таблицы символов. Во время прогона оставьте рабочий стол доступным для тестовых щелчков и ввода.

Флаг `-StoreCalculator` добавляет запуск установленного «Калькулятора» Microsoft Store через Launchpad. Тест сопоставляет окно с идентификатором пакета Windows, проверяет индикатор Dock и возврат свёрнутого окна. Ранее открытое окно калькулятора останется открытым.

Следующие команды выполните в тестовой учётной записи. Для проверки обновления используется локальная сборка-фикстура 0.9.0. Её сборочный сценарий ставит ранний номер версии в приложение и установщик. Если доступна ранее поставленная версия продукта, укажите её установщик в `-PreviousInstaller`.

~~~powershell
$testSid = [Security.Principal.WindowsIdentity]::GetCurrent().User.Value
.\scripts\Build-UpgradeFixture.ps1
.\tests\Install.Tests.ps1 -ExpectedUserSid $testSid -PreviousInstaller .\build\upgrade-fixture\0.9.0\release\0.9.0\LunarisDock-0.9.0-x64-Setup.exe
.\tests\Shell.Tests.ps1 -ExpectedUserSid $testSid -RestartExplorer
~~~

Сценарий установки проверяет установленную копию, закрытие работающей программы при обновлении, порядок закреплений, включение замены панели и автозапуска через настройки, а затем удаление. Временная папка журналов Inno записывается в консоль. Повторите сценарий оболочки с выключенным и включённым автоскрытием Windows. Для каждой попытки укажите результат после штатного выхода и после принудительного завершения основного процесса.

## Наблюдение за взаимодействием с Windows

Установите итоговый установщик и запустите Dock из меню приложений. Включите «Заменять панель задач» в настройках Dock. Запишите экран как минимум на частоте обновления дисплея, чтобы просмотреть переходы покадрово. При проверке Win+L используйте консоль гостевой машины или направьте системные сочетания внутрь тестового сеанса.

| Действие | Что должно произойти |
| --- | --- |

| По пять раз нажмите и отпустите левую Win, затем правую Win. Повторите с фокусом в другом обычном приложении. | Одиночные нажатия по очереди открыли и закрыли Launchpad. При покадровом просмотре во время каждого перехода отображались только рабочий стол и Launchpad. |
| Нажмите Win+E. | Открылось окно Проводника. Список приложений Dock остался закрытым. |
| Нажмите Win+R. Введите `winver`, нажмите Enter, закройте окно сведений. | Появился диалог «Выполнить» и из него открылось окно сведений Windows. |
| Откройте два окна и дважды нажмите Win+D. | Первый вызов показал рабочий стол. Второй восстановил окна. |
| Нажмите Win+Shift+S, выделите небольшую область тестового рабочего стола и вставьте снимок в Paint. | Открылась панель захвата Windows. Paint получил только выделенную область. |
| Нажмите Win+L и войдите повторно. Нажмите Win, затем Esc. | Сеанс заблокировался. После разблокировки Win открыла Launchpad ровно один раз и Esc его закрыл. |
| Включите «Скрывать Dock в развёрнутых окнах» и закройте настройки. Откройте полноэкранное приложение, затем развёрнутое окно. В каждом случае подведите курсор к нижнему краю экрана. Повторите с выключенным автоскрытием. | При включённом автоскрытии Dock скрывается в обоих случаях и появляется у края. При выключенном остаётся видимым. | Отключите замену в настройках, включите её снова и выйдите командой «Выйти из Dock». Нажмите Win. | После отключения и выхода положение и автоскрытие штатной панели совпали с исходными, Win открыла системный «Пуск». |
| Включите автозапуск и замену. Выйдите из тестовой учётной записи и войдите обратно. Затем удалите Dock через установленные приложения Windows. | При новом входе появился Dock. После удаления доступна исходная панель, одиночная Win открывает системный Пуск, запись автозапуска и ярлык исчезли. |

## Масштаб и доступность приложений

1. В параметрах гостевой Windows выберите масштаб 100% для основного монитора. После применения масштаба перезапустите Dock. Снимите полный экран с Dock и с открытым Launchpad.
2. Повторите при 150%. Если Windows требует повторного входа для применения масштаба, выполните его. Убедитесь, что панель целиком внутри экрана, указатель попадает в значки, подписи остаются читаемыми, увеличение не перекрывает соседние элементы. Проверьте, что поиск, стрелки страниц и кнопки настроек доступны.
3. Пройдите сетку до последней страницы стрелками и Page Down, затем вернитесь на первую. Проверьте поиск и запуск приложения Microsoft Store и обычной программы. При работе с длинным именем проверьте доступность полного названия.
4. Закрепите две программы, поменяйте порядок перетаскиванием, перезапустите Dock. Сравните порядок и вручную переключитесь между двумя окнами одной программы. Зафиксируйте вид индикаторов и положение активного окна.
