# Проверка переносимой сборки

В корне проекта выполните команду для выпуска ZIP.

```powershell
.\build.ps1 -PortableOnly
```

Быстрая проверка работает без открытия окон. Она сверяет SHA-256 и состав архива, читает конфигурацию извлечённого EXE и проверяет расположение обоих профилей из посторонней рабочей папки.

```powershell
.\tests\Portable.Tests.ps1 -PackageOnly
```

Для полного прогона понадобятся «Таблица символов» и «Калькулятор» Microsoft Store. Следующая команда временно переключает ввод на отдельный тестовый рабочий стол этого сеанса. В конце она возвращает исходный рабочий стол и на нём проверяет запуск и переключение окна Калькулятора. Именно там Windows активирует приложения Store. На время прогона оставьте мышь и клавиатуру свободными.

```powershell
.\qa\Capture.ps1 -RunPortableTests -OutputDirectory "$PWD\build\test-results\portable"
```

Тест извлекает ZIP в новую папку с пробелами и кириллицей. Сначала он запускает `--preview` с пустой переменной `LUNARIS_PROFILE` и дожидается записи `Data\Preview\settings.json`. После выхода он подготавливает известный порядок двух приложений и меняет размер Dock в тестовом профиле. Затем переносит всю папку, запускает копию из нового места и проверяет порядок и размер видимых кнопок, чтение настроек и команды `--preview --toggle` и `--preview --exit`.

Далее запускаются Core и Preview. Они проверяют Пуск, выбор темы, перетаскивание и сохранение закреплений, переключение окон, запуск обычного приложения и приложения Store. С развёрнутым и полноэкранным окном проверяется скрытие и вызов Dock у края. При наличии двух дисплеев тест переключает расположение Dock в настройках. После прогона сравнивается состояние профилей установленной версии, записи автозапуска и панели задач. Для прогона непосредственно на активном рабочем столе используется `.\tests\Portable.Tests.ps1`; для английской локализации передайте этому сценарию `-LaunchName 'Character Map'`.

Журналы находятся в `build\test-results\1.3.0\portable`. В `package.txt` и `full.txt` записана контрольная сумма проверенного ZIP. При ошибке журнал указывает временную папку с материалами прогона.

Проверки замены панели, клавиши Win и восстановления после сбоя выполняйте в отдельном сеансе или виртуальной машине по [инструкции по оболочке](Проверка%20оболочки.md). Самостоятельные Core, Preview, Shell и сценарий съёмки по умолчанию используют EXE в `release\1.3.0\LunarisDock-Portable`. Сценарий установки и удаления использует установщик.
